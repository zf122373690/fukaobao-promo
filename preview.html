IPv6 公网访问特别说明
  • DDNS 更新成功只代表域名已解析到设备 IPv6，不代表公网一定可以访问。
  • 需要在路由器或运营商光猫中开放 IPv6 防火墙，并允许外部访问设备使用的 Web 端口。
  • 部分运营商会屏蔽 IPv6 的 80 端口；遇到无法访问时，可在系统设置中更换 Web 端口，并同步放行新端口。
